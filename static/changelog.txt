Version: 2.1.4
Date: 2026-08-21
  Features:
    - Ported entirely to the fcore reactive UI engine with virtual DOM diffing and bucketed scheduling.
    - Added collapsible Admin Batch Replace panel with WellFold in the Settings tab.
    - Active Global Networks now applies the selected network signal and mask immediately upon clicking a preset slot.
  Optimizations:
    - Massively optimized live signal priorities polling: added memoization for signal keys and snapshot caching for world inventories.
    - Zero UPS overhead when GUI windows are closed.
  Bugfixes:
    - Fixed crash when closing equipment grids (armor, spidertron) in multiplayer (on_gui_closed).
    - Fixed slot button count formatting for string values like '-' and placeholders.
    - Fixed window expand/collapse sprite rendering in Factorio 2.0.

Version: 2.1.1
Date: 2026-08-09
  Features:
    - Added Settings tab inside the combinator window: configure your defaults for negative signals, station priority, network signal, network flag, stacks, count, and input mode (Counts vs Stacks).
    - Added "Apply to all combinators" checkboxes: when saving settings as admin, all your existing combinators with matching values will be batch-updated.
    - New combinators now automatically use your saved defaults for priority and network mask.
    - When adding a new signal to a group, the default count is now 1 item/fluid (or 1 full stack in Stacks mode) instead of leaving it empty.
    - Input fields now auto-focus when you open the combinator window.
    - Old save files with existing combinators are automatically migrated to the new internal layout.
  Bugfixes:
    - Fixed copy-pasting settings from a vanilla constant combinator into this combinator: sections are now correctly arranged instead of being misplaced.
    - Fixed missing dropdown handler in group rename presets.
    - Fixed output statistics not updating when toggling group checkboxes.
    - Fixed GUI not closing properly when mining or destroying the combinator.
    - Fixed preset dropdown selection not populating the rename field.
    - Fixed button captions resetting during group edit.
    - Fixed checkbox rendering errors.
    - Fixed crashes during save/load and when new players join.

Version: 2.1.0
Date: 2026-08-05
  Features:
    - Added "Open Networks" button: see all network flags used across your factory and select one with a single click.
    - Added 32-bit Bitmask Encoder: click individual bits (0-31) to compose network masks, with real-time decimal value display.
    - Added dual Stacks / Count inputs: edit both simultaneously with automatic stack size calculations. The active mode is highlighted in bold.
    - Full ghost support: you can now open and configure combinators placed as ghosts (blueprints, ghost cursor). All settings are preserved when a robot builds them.
    - New combinators automatically start with your chosen default priority and network flag (A1 by default).
    - Signal icons now show compact counts like 1.2k, 50k, 1.2M instead of long numbers.
    - Auto-scroll to newly added groups and group editors.
  Bugfixes:
    - Fixed input field focus jumping incorrectly when switching between items and fluids.
    - Fixed network mask and stacks inputs now correctly allow typing a minus sign (-) mid-input.
    - Fixed output statistics to only count real items and fluids, ignoring virtual signals.
    - Fixed copy-paste between combinators and ghosts.
